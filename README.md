# File Handling Project – Python

A simple Python project created to practice **file handling operations** in Python, including reading, writing, appending, and managing files.

## 📌 Project Overview

This project demonstrates the basics of file handling in Python and shows how Python programs can work with external files for storing and retrieving data.

## 🛠️ Technologies Used

- **Python**
- Python File Handling
- File I/O

## ✨ Concepts Covered

- Opening files using `open()`
- Reading file contents
- Writing data to files
- Appending data to files
- Closing files
- File modes:
  - `r` – Read
  - `w` – Write
  - `a` – Append
  - `x` – Create
